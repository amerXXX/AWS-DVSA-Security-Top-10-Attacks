# Replication Guide

This repository is organized by lesson so a beginner can reproduce the project step by step.

## Recommended Order
1. Lesson 1 / Lesson 9: Event Injection and Vulnerable Dependencies
2. Lesson 2: Broken Authentication
3. Lesson 3: Sensitive Data Exposure
4. Lesson 4: Insecure Cloud Configuration
5. Lesson 5: Broken Access Control
6. Lesson 6: Denial of Service
7. Lesson 7: Over-Privileged Function
8. Lesson 8: Logic Vulnerability
9. Lesson 10: Unhandled Exceptions

## How to Use This Repo
- Read the final report for the full 10-part write-up.
- Open the matching screenshot folder for evidence.
- Open the related extracted Lambda package under `fixes/`.
- Use the sample commands under `scripts/`.
- Record your own screenshots when reproducing in AWS.

## Reminder
If a lesson behaves differently because of AWS updates, keep the evidence and explain how you tested it.
